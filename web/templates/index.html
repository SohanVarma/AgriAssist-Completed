AgriAssist Intelligence

Multimodal agricultural intelligence in one system

AgriAssist combines crop disease image classification, retrieval-augmented generation, explainable AI, and OpenAI-powered advisory generation to support farmers with safer and more evidence-based recommendations.

🌿

Crop Disease Classification

  • Image upload prediction
  • Confidence scoring
  • Evaluation metrics

Working RAG Pipeline

System Workflow

How the advisory is generated

01

User Input

The user enters a crop problem or uploads a crop image.

02

Prediction / Retrieval

The system predicts the image class or retrieves relevant agricultural records.

03

AI Analysis

OpenAI analyzes the retrieved evidence and prepares an advisory report.

04

Safety Guidance

The final report includes limitations and expert-verification warnings.

01

Ask by Text

Enter a crop problem such as tomato leaf curl, wheat rust, irrigation issue, or brinjal equipment problem.
