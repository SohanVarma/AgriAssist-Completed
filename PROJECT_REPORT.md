# AgriAssist: Multimodal Crop Disease Diagnosis and Advisory System

## Abstract
AgriAssist is an AI-powered agricultural assistance system designed to detect crop diseases from leaf images and provide localized multilingual advisories for farmers. The project combines computer vision, synthetic data augmentation, configurable datasets, and explainable AI concepts into a deployable research prototype.

## Objectives
- Detect crop diseases using deep learning
- Provide localized farmer advisories
- Support multilingual recommendations
- Reduce dependency on expert intervention for early disease detection
- Build a configurable research-grade AI pipeline

## Technologies Used
- Python
- PyTorch
- Streamlit
- Scikit-learn
- PIL
- Matplotlib

## System Architecture
1. Dataset ingestion
2. Data preprocessing pipeline
3. CNN-based disease classification
4. Advisory generation
5. Streamlit deployment interface
6. Evaluation and explainability layer

## Dataset Sources
- Kaggle New Plant Diseases Dataset
- PlantVillage Dataset
- ICAR Agricultural Publications

## Features Implemented
- Configurable dataset system
- Automatic dataset downloader
- CNN image classifier
- Synthetic data augmentation demo
- Multilingual farmer advisory
- Streamlit frontend
- Confusion matrix generation
- Classification report generation
- Safety disclaimers

## Future Scope
- Vision Transformer integration

## Conclusion
AgriAssist demonstrates how AI can improve agricultural accessibility by combining image classification, advisory generation, and user-friendly deployment into a practical farming support system.
